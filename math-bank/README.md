# 高等数学题库（离线版）

按同济大学《高等数学》**十二章**分类的本地题库，支持题目检索、增删改、JSON 导入导出、随机组题，以及直接生成 Word（`.docx`）试卷。

整个页面没有任何联网请求、外部字体或第三方库。双击 `index.html` 就能使用。

## 打开方式

1. 双击 `index.html`，或把它拖进 Chrome / Edge / Firefox。
2. 第一次打开会自动载入内置题库（目前内置 186 道题：第一章 49 道，其中 2 道中档；第二章 54 道，其中 2 道中档；第三章 72 道，其中 3 道中档；第四章 11 道，其中 2 道中档、2 道较难）。也可以：
   - 点「新增题目」手工录入；
   - 点「载入演示题」加入 9 道演示题，体验检索和组卷；
   - 在「数据」页拖入 JSON 文件或粘贴 JSON。

> 以后在 `data/questions.js` 里新增的题，刷新页面会自动补入已有题库；删掉过的内置题不会被自动加回。修改已有内置题的内容时，在「数据」页点「合并内置题库」覆盖更新。清空整个题库后不会自动重新载入。

> 推荐 Chrome / Edge。页面通过 `file://` 直接运行，不需要 Node、Python 或本地服务器。

## 功能

- **十二章分类**：函数与极限、导数与微分、微分中值定理与导数的应用、不定积分、定积分、定积分的应用、微分方程、向量代数与空间解析几何、多元函数微分法及其应用、重积分、曲线积分与曲面积分、无穷级数。
- **题库**：按章节 / 题型 / 难度筛选，全文搜索题干、答案、解析、标签和来源；可展开答案、编辑、删除。
- **组题**：选择章节范围、题型、难度和数量，从符合条件的题目中不重复地随机抽取；可单题「换一题」或移除。
- **Word 导出**：A4、宋体正文、黑体标题、页脚页码；可选是否附答案、是否附解析、题目之间是否留答题空间。答案会另起一页。
- **本地优先**：题目写入浏览器 `localStorage`，不经过网络；支持 JSON 导出备份和合并导入。
- **数据可迁移**：导出的 JSON 可在另一台电脑导入，也可以作为内置题库分发。

## 数据存在哪里

题目保存在浏览器的 `localStorage` 中：

- 换浏览器、换电脑、清理浏览器数据、移动文件夹后，原题库可能不可见。
- **请定期在「数据」页导出 JSON 备份。**
- 当前页面是 `file://` 直接打开的离线页面，浏览器会把它视作本地文件；不同浏览器对本地文件存储的具体行为可能略有差异。遇到无法写入的提示时，优先导出备份，或改用 Chrome / Edge。

## 加题方式

### 方式一：页面里新增 / 批量导入

在「题库」页新增，或在「数据」页导入 JSON。导入支持两种模式：

- **合并导入**：相同 `id` 更新，新 `id` 追加；
- **覆盖题库**：清空当前题库后导入。

### 方式二：写进内置题库

把题目条目放进 [`data/questions.js`](data/questions.js) 的 `window.TJ_BUILTIN_QUESTIONS` 数组。首次打开会自动载入；以后新增的条目在刷新页面后自动补入已有题库。已经删除的内置题不会被自动加回；修改已有条目的内容时，到「数据」页点「合并内置题库」，相同 id 会更新，其余题目追加。

### JSON 字段

```json
{
  "version": 1,
  "questions": [
    {
      "id": "ch01-001",
      "chapter": "第1章",
      "type": "计算题",
      "difficulty": "基础",
      "stem": "求极限 lim_{x→0} (sin 3x) / x",
      "answer": "3",
      "solution": "利用等价无穷小 sin 3x ~ 3x。",
      "tags": ["极限", "等价无穷小"],
      "source": "自编"
    }
  ]
}
```

字段说明：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `stem` | 是 | 题干；也兼容 `question` / `content` |
| `chapter` | 是 | `ch01`–`ch12`、`1`–`12`、`第1章` 或章节全名 |
| `type` | 否 | 选择题 / 填空题 / 计算题 / 证明题 / 解答题 / 应用题；缺省按解答题 |
| `difficulty` | 否 | 基础 / 中等 / 较难，或 1 / 2 / 3；缺省按中等 |
| `id` | 否 | 导入时自动生成；相同 id 在合并模式下会更新 |
| `answer` | 否 | 答案 |
| `solution` | 否 | 解析；也兼容 `analysis` / `explanation` |
| `tags` | 否 | 字符串数组，或用逗号分隔的字符串 |
| `source` | 否 | 来源 |

可以直接下载「数据」页里的「导入模板」作为起点。也可以参考 [`data/import-example.json`](data/import-example.json)。

## 公式写法

页面内置离线 KaTeX，不需要联网。题目、答案、解析里都可以混用中文和 LaTeX：

- 行内公式：`$\lim_{x\to 0}\frac{\sin x}{x}$`
- 独立公式：`$$\int_0^1 x^2\,dx$$`
- 也支持 `\(...\)`、`\[...\]` 两种定界符。
- 旧的 Unicode / 上下标写法继续可用：`x^{2}`、`a_{n}`、`√`、`∫`、`π`。
- 想输出普通美元符号，写成 `\$`。

编辑器里有实时「公式预览」。**第一至四章共 186 道题已迁移为 LaTeX**；页面显示走 KaTeX，Word 导出时公式走 MathJax → PNG。

迁移时会把常见的线性写法自动整理成 LaTeX：`e^(-x)` → `e^{-x}`、`sinx` → `\sin x`、`\lim (x\to 0)` → `\lim_{x\to 0}`、`³√` → `\sqrt[3]{}`。

导出 Word 时，`$...$` 里的公式会变成内嵌 PNG 图片，正文中文保持可编辑文本；因此 Word 里的公式本身不能再直接改。公式转图片失败时会回退到迁移前原文。

## 实现说明

- Word 导出是在浏览器内直接拼装 OOXML 并打包成 ZIP，不依赖 Word、Office JS、docx 库或服务器。
- 页面渲染用离线 KaTeX；Word 导出时按需加载离线 MathJax，把每个公式栅格化成 PNG 后嵌入。
- 迁移前的原文保存在 `stemPlain` / `answerPlain` / `solutionPlain`，公式图片生成失败时回退到原文。
- 组卷是一次性随机抽取，不重复；筛选范围内的题不够时，会选入全部并在预览里提示。
- 打印样式已内置：在组题预览上方点「打印」，可直接打印试卷或另存为 PDF。

## 当前版本边界

- 不支持多人协作、云端同步；每台电脑的题库数据相互独立。
- 暂不支持图片题、按题型自动分大题；公式编辑目前是 LaTeX 源码 + 实时预览，不是可视化公式面板。
- Word 里的公式是图片，不能在 Word 内直接编辑公式。
- 清空题库不可撤销，请先导出 JSON。
