第一章 函数、极限与连续

一、填空题过程

分子有理化：原式 = [(n+2)-(n-1)] / [√(n+2) + √(n-1)] = 3 / [√(n+2) + √(n-1)]。当 n→∞ 时，分母趋于无穷，故极限为 0。

分子分母同除以 x：原式 = (1 + 3sinx/x) / (3 + 5sinx/x)。因为 x→∞ 时，sinx/x → 0，所以极限为 1/3。

分子分母同除以 x^50。分子最高次项系数为 2^30 × 3^20，分母最高次项系数为 2^50。原式 = (2^30 × 3^20) / 2^50 = (3/2)^20。

凑重要极限：原式 = [(1 - 2/x)^(-x/2)]^(-2)。当 x→∞ 时，中括号内趋于 e，故极限为 e^(-2)。

等价无穷小：当 x→∞ 时，sin[3x/(2x^2+1)] ~ 3x/(2x^2+1)。原式 = x × [3x/(2x^2+1)] = 3x^2/(2x^2+1) → 3/2。

拆成两项：lim x·sin(1/x) = lim sin(1/x)/(1/x) = 1；lim (1+1/x)^x = e。故原极限为 1 + e。

等价无穷小：当 x→0 时，ln(1+ax^2) ~ ax^2。已知与 x^2 等价，故 a = 1。

连续要求左右极限相等。右极限 lim(x→0+) arctan(1/x) = π/2。左极限 lim(x→0-) (k+e^(-x)) = k+1。令 k+1 = π/2，得 k = π/2 - 1。

右极限 lim(x→0+) (a-e^(-x)) = a-1。左极限 lim(x→0-) (x+1) = 1。令 a-1 = 1，得 a = 2。

因式分解得 f(x) = (x-1)(x+1) / [(x-1)(x-2)]。x=1 为可去间断点（第一类），x=2 为无穷间断点（第二类）。填 x=1。

因式分解得 f(x) = (x-1)(x+1) / [x(x-1)]。x=1 为可去间断点，x=0 为无穷间断点。填 x=0。

定义域 x>0 且 x≠1, x≠2。x=1 为可去间断点；x=2 时，分子非零分母趋于零，为无穷间断点（第二类）。填 x=2。

定义域 x>1。当 x→2 时，分母 ln(x-1)→0，分子→1，趋于无穷。填 x=2。

三、解答题过程

求 lim(x→0) (tanx - sinx) / (x·ln(1+x^2))
解：分母等价替换：ln(1+x^2) ~ x^2。分子化简：tanx - sinx = tanx(1 - cosx)。当 x→0 时，tanx ~ x，1-cosx ~ x^2/2。
原极限 = lim(x→0) [x·(x^2/2)] / (x·x^2) = 1/2。

求 lim(x→0) (1 - cos(x^2)) / (x^2·ln(1+sin^2x))
解：分子 1-cos(x^2) ~ (x^2)^2/2 = x^4/2。分母中 ln(1+sin^2x) ~ sin^2x ~ x^2，所以分母 ~ x^2·x^2 = x^4。
原极限 = lim(x→0) (x^4/2) / x^4 = 1/2。

求 lim(x→0) (e - e^(cosx)) / (³√(1+x^2) - 1)
解：分母等价替换：³√(1+x^2) - 1 ~ (1/3)x^2。分子提公因式：e^(cosx)(e^(1-cosx) - 1)。因为 e^(1-cosx) - 1 ~ 1-cosx ~ x^2/2，且 x→0 时 e^(cosx) → e。
原极限 = lim(x→0) [e·(x^2/2)] / [(1/3)x^2] = (e/2) / (1/3) = 3e/2。

求 lim(x→0) (³√(cosx) - cosx) / sin^2x
解：利用公式 a^3 - b^3 = (a-b)(a^2+ab+b^2)。设 a=³√(cosx)，b=cosx，则 a^3-b^3 = cosx - cos^3x = cosx(1-cos^2x) = cosx·sin^2x。
所以 ³√(cosx) - cosx = cosx·sin^2x / (a^2+ab+b^2)。
当 x→0 时，cosx→1，分母 a^2+ab+b^2 → 1+1+1 = 3。
原极限 = lim(x→0) [cosx·sin^2x / 3] / sin^2x = lim(x→0) cosx / 3 = 1/3。

求分段函数的间断点并判断类型。f(x)=x^2+2x (x≤0); f(x)=1+x (0<x≤1); f(x)=1/(x-1) (x>1)
解：
(1) 考察分段点 x=0：左极限 lim(x→0-) (x^2+2x) = 0；右极限 lim(x→0+) (1+x) = 1。左右极限存在但不相等，故 x=0 是跳跃间断点（第一类）。
(2) 考察分段点 x=1：左极限 lim(x→1-) (1+x) = 2；右极限 lim(x→1+) 1/(x-1) = +∞。右极限不存在，故 x=1 是无穷间断点（第二类）。

四、证明题过程

证明方程 x^5 + x - 1 = 0 在 (0,1) 内至少有一个根。
证明：构造函数 f(x) = x^5 + x - 1。因为 f(x) 是初等函数，在闭区间 [0,1] 上连续。
计算端点值：f(0) = -1 < 0，f(1) = 1 + 1 - 1 = 1 > 0。
根据零点定理，f(0)·f(1) < 0，故至少存在一点 ξ ∈ (0,1)，使得 f(ξ) = 0。即方程至少有一个根。

设 f(x) 在 [0,a] 上连续，且 f(0)=f(a)，证明：存在 ξ ∈ (0,a) 使 f(ξ)=f(ξ+a/2)。
证明：构造函数 F(x) = f(x) - f(x+a/2)。F(x) 在 [0, a/2] 上连续。
计算端点值：F(0) = f(0) - f(a/2)；F(a/2) = f(a/2) - f(a) = f(a/2) - f(0)。
若 F(0) = 0，则取 ξ = 0；若 F(a/2) = 0，则取 ξ = a/2。
若均不为0，则 F(0) 与 F(a/2) 互为相反数（即符号相反）。根据零点定理，存在 ξ ∈ (0, a/2) ⊂ (0, a)，使得 F(ξ) = 0，即 f(ξ)=f(ξ+a/2)。得证。

证明：方程 x - 2sinx = 3 至少有一个正根。
证明：构造函数 f(x) = x - 2sinx - 3。在闭区间 [0, π] 上连续。
f(0) = 0 - 0 - 3 = -3 < 0。
f(π) = π - 0 - 3 = π - 3 > 0。
由于 f(0)·f(π) < 0，由零点定理，至少存在 ξ ∈ (0, π)，使得 f(ξ) = 0。显然 ξ > 0，故方程至少有一个正根。

三、解答题过程

设 y = x^(cosx)，求 dy/dx。
解：两边取自然对数：ln y = cosx·ln x。
两边对 x 求导：(1/y)·y' = -sinx·ln x + cosx·(1/x)。
所以 y' = x^(cosx) · [cosx/x - sinx·ln x]。

设 y = (sinx)^x，求 dy/dx。
解：两边取对数：ln y = x·ln(sinx)。
对 x 求导：(1/y)·y' = ln(sinx) + x·(cosx/sinx) = ln(sinx) + x·cotx。
所以 y' = (sinx)^x · [ln(sinx) + x·cotx]。

设 x=2e^t, y=e^(-t)，求 dy/dx。
解：dx/dt = 2e^t，dy/dt = -e^(-t)。
dy/dx = (dy/dt) / (dx/dt) = -e^(-t) / 2e^t = -(1/2)e^(-2t)。

设 x=cos2t, y=sin2t，求 d^2y/dx^2。
解：dx/dt = -2sin2t，dy/dt = 2cos2t。
dy/dx = (2cos2t) / (-2sin2t) = -cot(2t)。
d^2y/dx^2 = d(dy/dx)/dx = [d(-cot2t)/dt] / (dx/dt) = [2csc^2(2t)] / (-2sin2t) = -1/sin^3(2t) = -csc^3(2t)。

设 x=sin(t/2), y=e^t，求 dy/dx 及 t=0 时的值。
解：dx/dt = (1/2)cos(t/2)，dy/dt = e^t。
dy/dx = e^t / [(1/2)cos(t/2)] = 2e^t / cos(t/2)。
当 t=0 时，dy/dx = 2(1) / cos(0) = 2。

设 x=5(t-sint), y=5(1-sint)，求 d^2y/dx^2。
解：dx/dt = 5(1-cost)，dy/dt = -5cost。
dy/dx = -5cost / [5(1-cost)] = -cost / (1-cost)。
d^2y/dx^2 = d(dy/dx)/dx = [d(-cost/(1-cost))/dt] / [5(1-cost)]。
分子求导：[sint(1-cost) - (-cost)(sint)] / (1-cost)^2 = [sint - sint·cost - sint·cost] / (1-cost)^2 = sint(1-2cost) / (1-cost)^2。

设 y=1+xe^y 确定 y=y(x)，求 dy。
解：两边微分：dy = dx·e^y + x·e^y·dy。
整理得：dy(1 - xe^y) = e^y dx。由于 xe^y = y - 1，代入得 1 - xe^y = 2 - y。
所以 dy = [e^y / (2 - y)] dx。

设 y^5+2y-x-3x^7=0 确定 y=y(x)，求 y'(0)。
解：当 x=0 时，y^5+2y=0，解得 y=0。
方程两边对 x 求导：5y^4·y' + 2y' - 1 - 21x^6 = 0。
代入 x=0, y=0：0 + 2y'(0) - 1 - 0 = 0，得 y'(0) = 1/2。

讨论 f(x)=x^2sin(1/x) (x≠0); f(0)=0 在 x=0 的连续性与可导性。
解：连续性：lim(x→0) x^2sin(1/x) = 0（无穷小乘有界函数）。因为极限等于函数值 f(0)，所以在 x=0 处连续。
可导性：f'(0) = lim(x→0) [f(x)-f(0)] / x = lim(x→0) x·sin(1/x) = 0。极限存在，故在 x=0 处可导。

设 f(x)=x-1 (x<1); f(x)=x^2-1 (x≥1)，用左右导数定义求 x=1 处导数。
解：左导数 f'-(1) = lim(x→1-) [f(x)-f(1)] / (x-1) = lim(x→1-) [(x-1)-0] / (x-1) = 1。
右导数 f'+(1) = lim(x→1+) [f(x)-f(1)] / (x-1) = lim(x→1+) [(x^2-1)-0] / (x-1) = lim(x→1+) (x+1) = 2。
因为左右导数不相等，故函数在 x=1 处不可导。

设 f(x)=√(1+4x)-1 (x>0); f(x)=ax+b (x≤0)。问 a,b 为何值时 f(x) 在 x=0 可导？
解：可导必连续。右极限 lim(x→0+) (√(1+4x)-1) = 0，左极限 lim(x→0-) (ax+b) = b。故 b=0。
右导数：f'+(0) = lim(x→0+) [√(1+4x)-1 - 0] / x = lim(x→0+) (4x) / [x(√(1+4x)+1)] = 2。
左导数：f'-(0) = lim(x→0-) [(ax+0)-0] / x = a。
可导要求左右导数相等，故 a=2。

设 f(x)=x^2 (0≤x≤1); f(x)=ax+b (1<x≤2) 在 x=1 处可导，求 a,b。
解：连续性：f(1) = 1；右极限 lim(x→1+) (ax+b) = a+b。故 a+b=1。
可导性：左导数 f'-(1) = 2x|(x=1) = 2；右导数 f'+(1) = a。故 a=2。
代回 a+b=1，得 b=-1。

设 f(x)=1-√(1-x) (x<0); f(x)=a+bx (x≥0) 处处可导，求 a,b。
解：连续性：左极限 lim(x→0-) (1-√(1-x)) = 0；右极限 f(0)=a，故 a=0。
可导性：左导数 f'-(0) = lim(x→0-) [1-√(1-x)] / x = lim(x→0-) x / [x(1+√(1-x))] = 1/2。
右导数 f'+(0) = b。左右导数相等，故 b=1/2。

求 lim(x→0) [1/(e^x-1) - 1/sinx]。
解：通分：原式 = lim(x→0) (sinx - e^x + 1) / [(e^x-1)sinx]。
分母 (e^x-1)sinx ~ x·x = x^2。
分子在 x=0 处用麦克劳林公式：sinx ~ x - x^3/6，e^x ~ 1 + x + x^2/2。所以分子 = x - (1+x+x^2/2) + 1 = -x^2/2。
原极限 = lim(x→0) (-x^2/2) / x^2 = -1/2。

求 lim(x→0+) x^x。
解：改写为 lim(x→0+) e^(x·lnx)。考虑指数极限 lim(x→0+) x·lnx。
用洛必达法则：lim(x→0+) lnx / (1/x) = lim(x→0+) (1/x) / (-1/x^2) = lim(x→0+) (-x) = 0。
原极限 = e^0 = 1。

求 f(x)=x+2√(1-x) 的单调区间和极值。
解：定义域 x≤1。f'(x) = 1 - 1/√(1-x) = [√(1-x) - 1] / √(1-x)。
令 f'(x)=0，得 √(1-x)=1，x=0。
当 x<0 时，f'(x)>0，单调递增；当 0<x<1 时，f'(x)<0，单调递减。
极大值为 f(0) = 0 + 2 = 2。无极小值。

求 f(x)=e^(-x)(x+1) 在 [1,3] 上的最值。
解：f'(x) = -e^(-x)(x+1) + e^(-x) = -x·e^(-x)。
当 x∈[1,3] 时，f'(x) < 0，函数单调递减。
最大值在 x=1 处：f(1) = 2/e。
最小值在 x=3 处：f(3) = 4/e^3。

求 y=2x^3+3x^2-12x+1 的凹凸区间及拐点。
解：y' = 6x^2+6x-12，y'' = 12x+6。
令 y''=0，得 x=-1/2。
当 x<-1/2 时，y''<0，为凸区间；当 x>-1/2 时，y''>0，为凹区间。
当 x=-1/2 时，y = 2(-1/8) + 3(1/4) - 12(-1/2) + 1 = 15/2。拐点为 (-1/2, 15/2)。

f(x)=x^3+ax^2+bx 在 x=1 处有极值 -2，求 a,b 及凹凸区间和拐点。
解：f'(x) = 3x^2+2ax+b。由题意 f(1)=-2，f'(1)=0。
1+a+b=-2；3+2a+b=0。解得 a=0, b=-3。
f(x) = x^3-3x。f''(x) = 6x。令 f''(x)=0，x=0。
当 x>0 时 f''>0（凹区间）；当 x<0 时 f''<0（凸区间）。拐点为 (0,0)。

求 f(x)=e^x 带有佩亚诺余项的 3 阶麦克劳林公式。
解：由公式 f(x) = f(0) + f'(0)x + f''(0)x^2/2! + f'''(0)x^3/3! + o(x^3)。
f(x)=e^x 的各阶导数均为 e^x，在 x=0 处均为 1。
故 e^x = 1 + x + x^2/2 + x^3/6 + o(x^3)。

无盖圆柱水池，V=2π，底价 2，侧价 1，求最省造价的直径与高之比。
解：设底面半径为 r，高为 h。V = πr^2h = 2π，得 h = 2/r^2。
造价 C = 2·πr^2 + 1·(2πrh) = 2πr^2 + 2πr(2/r^2) = 2πr^2 + 4π/r。
求导：C' = 4πr - 4π/r^2 = 0，得 r=1。此时 h=2。
直径 D=2r=2，所以 D:h = 2:2 = 1:1。

最大利润问题。C(x)=3800+5x-x^2/1000, P(x)=50-x/100。
解：利润 L(x) = x·P(x) - C(x) = x(50-x/100) - (3800+5x-x^2/1000) = -9x^2/1000 + 45x - 3800。
L'(x) = -18x/1000 + 45 = 0，解得 x = 2500。
由于 L''(x) = -18/1000 < 0，所以 x=2500 时利润最大。

傍河岸等腰三角形鱼池，腰总长 20，高为 x，求最大面积。
解：设底边长为 b，两腰各长 10。高 x 对应底边的一半为 √(10^2-x^2) = √(100-x^2)。
底边 b = 2√(100-x^2)。面积 S(x) = (1/2)·b·x = x√(100-x^2)。
令 S^2 = x^2(100-x^2)，当 x^2=50 时取得最大，即 x=5√2。此时底边 b=10√2。
最大面积时，高为 5√2 米，底边为 10√2 米。

靠墙盖长方形小屋，砖够砌 20 米墙，求长宽。
解：设靠墙边长为 y，垂直墙的边长为 x。则 y + 2x = 20（靠墙侧不砌砖），即 y = 20-2x。
面积 S = xy = x(20-2x) = 20x - 2x^2。
S' = 20 - 4x = 0，x=5。此时 y=10。
当 x=5米，y=10米时面积最大。

圆柱形锅炉，V，底面价 1，侧面价 2，求最省材料直径高比。
解：设半径 r，高 h。V=πr^2h。造价 C = 2·πr^2 + 2·(2πrh) = 2πr^2 + 4πrh。
代入 h = V/(πr^2)，C(r) = 2πr^2 + 4V/r。
C'(r) = 4πr - 4V/r^2 = 0，得 r = ³√(V/π)。此时 h = ³√(V/π)。
所以 D:h = 2r:h = 2:1。

边长 48 正方形铁皮，四角截去正方形做方盒，求最大容积。
解：设截去小正方形边长为 x。盒底边长 48-2x，高 x。
V = x(48-2x)^2，0<x<24。V' = (48-2x)^2 + x·2(48-2x)(-2) = (48-2x)(48-6x)。
令 V'=0，得 x=8 或 x=24（舍）。当 x=8 时容积最大。

内接于半径 1 的圆，面积最大的矩形。
解：设矩形长宽分别为 2a, 2b，则 a^2+b^2=1。面积 S=4ab。
S = 4a√(1-a^2)。S^2 = 16a^2(1-a^2)。
当 a^2 = 1/2 时最大，即 a=b=√2/2。此时矩形边长为 √2 和 √2，为正方形。

防空洞截面积 5，上为半圆下为矩形，求最省材料尺寸。
解：设半圆半径 r，矩形高 h。面积 S = 2rh + πr^2/2 = 5。
周长 L = πr + 2r + 2h = (π+2)r + 2h。由面积解得 h = (5 - πr^2/2) / (2r)。
代入 L = (π+2)r + 5/r - πr/2 = (π/2 + 2)r + 5/r。
L' = (π/2 + 2) - 5/r^2 = 0，得 r = √[10/(π+4)]。此时 h 也等于 √[10/(π+4)]。

扇形周长 a，求面积最大时的半径 x。
解：设半径 x，弧长 L。则 2x + L = a，即 L = a - 2x。
面积 S = (1/2)·x·L = (1/2)x(a-2x) = ax/2 - x^2。
S' = a/2 - 2x = 0，x = a/4。此时扇形面积最大。

四、证明题过程

利用微分中值定理证明 f'(c) > 0。
证明：因为 f(x) 在 [a,b] 连续，(a,b) 可导，由拉格朗日中值定理，存在 c ∈ (a,b)，使得 f'(c) = [f(b)-f(a)] / (b-a)。
已知 f(a) < f(b)，即 f(b)-f(a) > 0，且 b-a > 0，所以 f'(c) > 0。得证。

设 f(x) 在 [0,2] 连续 (0,2) 可导，f(2)=0。证明存在 ξ ∈ (0,2) 使 ξf'(ξ) + f(ξ) = 0。
证明：构造辅助函数 F(x) = x·f(x)。
F(x) 在 [0,2] 连续，(0,2) 可导。F(0) = 0，F(2) = 2f(2) = 0。
由罗尔定理，存在 ξ ∈ (0,2)，使得 F'(ξ) = 0。
由于 F'(x) = f(x) + x·f'(x)，故 f(ξ) + ξf'(ξ) = 0。得证。

设 f(x) 在 [0,a] 连续可导，f(a)=0。证明存在 ξ ∈ (0,a) 使 ξf'(ξ) + 2f(ξ) = 0。
证明：构造辅助函数 F(x) = x^2·f(x)。
F(0) = 0，F(a) = a^2·f(a) = 0。满足罗尔定理。
存在 ξ ∈ (0,a)，使 F'(ξ) = 2ξ·f(ξ) + ξ^2·f'(ξ) = 0。
因为 ξ ≠ 0，两边除以 ξ，得 2f(ξ) + ξf'(ξ) = 0。得证。

设 f(x) 在 [a,b] 连续可导，bf(a)=af(b)。证明存在 ξ ∈ (a,b) 使 ξf'(ξ) - f(ξ) = 0。
证明：构造辅助函数 F(x) = f(x)/x。
则 F(a) = f(a)/a，F(b) = f(b)/b。由 bf(a)=af(b) 两边同除以 ab 得 f(a)/a = f(b)/b，即 F(a) = F(b)。
由罗尔定理，存在 ξ ∈ (a,b)，使 F'(ξ) = [ξf'(ξ) - f(ξ)] / ξ^2 = 0。
即 ξf'(ξ) - f(ξ) = 0。得证。

设 f(a)=f(b)=0。证明存在 ξ ∈ (a,b) 使 λf(ξ) + f'(ξ) = 0。
证明：构造辅助函数 F(x) = e^(λx)·f(x)。
F(a) = e^(λa)f(a) = 0，F(b) = e^(λb)f(b) = 0。
由罗尔定理，存在 ξ ∈ (a,b)，使 F'(ξ) = λe^(λξ)f(ξ) + e^(λξ)f'(ξ) = 0。
因为 e^(λξ) ≠ 0，约去得 λf(ξ) + f'(ξ) = 0。得证。

证明 |arctan a - arctan b| ≤ |a - b|。
证明：设 f(x) = arctan x。f(x) 在任意区间上连续可导。
若 a=b，显然成立。若 a≠b，不妨设 a<b。由拉格朗日中值定理，存在 ξ ∈ (a,b)，使得 arctan b - arctan a = (1/(1+ξ^2))·(b-a)。
两边取绝对值：|arctan a - arctan b| = (1/(1+ξ^2))·|a - b|。
因为 1/(1+ξ^2) ≤ 1，所以 |arctan a - arctan b| ≤ |a - b|。得证。

证明当 x>0 时，x > arctan x。
证明：构造辅助函数 f(x) = x - arctan x。f(0) = 0。
f'(x) = 1 - 1/(1+x^2) = x^2/(1+x^2)。
当 x>0 时，f'(x) > 0，所以 f(x) 在 (0, +∞) 单调递增。
故 f(x) > f(0) = 0，即 x > arctan x。

证明当 x>0 时，e^x > 1 + x + x^2/2。
证明：构造辅助函数 f(x) = e^x - (1 + x + x^2/2)。f(0) = 0。
f'(x) = e^x - 1 - x。f'(0) = 0。
f''(x) = e^x - 1。当 x>0 时，f''(x) > 0，故 f'(x) 单调递增。
所以 f'(x) > f'(0) = 0，进而 f(x) 单调递增，f(x) > f(0) = 0。
即 e^x > 1 + x + x^2/2。得证。

证明方程 x = 2 + sinx 至少有一个不超过 3 的正根。
证明：构造函数 f(x) = x - 2 - sinx。在 [0,3] 上连续。
f(0) = 0 - 2 - 0 = -2 < 0。
f(3) = 3 - 2 - sin3 = 1 - sin3。因为 sin3 ≤ 1，所以 1 - sin3 ≥ 0。（若等于0，则3就是根）。
若 1 - sin3 > 0，由零点定理，在 (0,3) 内必存在一点是根。
综上，方程至少有一个不超过 3 的正根。得证。
